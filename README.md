# Todo App (React + Vite + Tailwind)

Thai-language todo app with priorities, inline editing, filters and animated delete.
Data lives in React state only (no localStorage).

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview  # preview the build
```

## Stack
React 18, Vite 5, Tailwind CSS 3, lucide-react.
